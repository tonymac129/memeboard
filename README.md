# [MemeBoard](https://memeboard-app.vercel.app)

Explore the trendiest memes, upload your own creations, and interact with the community!

## Features

- Upload custom memes
- Comment and discuss the memes
- Vote for the best memes and save to collections
- Share the memes and chat with friends
- Customize your own profile
- Follow your friends
